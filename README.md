# 🚴‍♂️ Sbike Cardio Basic (Offline)

Phần mềm hỗ trợ đạp xe trong nhà trên **Windows 11**, kết nối cảm biến nhịp đạp qua **BLE** hoặc **ANT+**, hiển thị dữ liệu realtime và lưu trữ hoàn toàn trên máy tính (**offline – không cần Internet**).

---

## ✨ Tính năng chính

* 🔗 Kết nối cảm biến nhịp đạp qua **Bluetooth (BLE)** hoặc **ANT+**
* 📊 Hiển thị realtime:

  * Tốc độ đạp
  * Nhịp đạp (RPM)
  * Quãng đường
* 💾 Lưu dữ liệu luyện tập **trực tiếp trên máy (local)**
* ⚡ Không cần đăng nhập, không cần mạng
* 🖥️ Giao diện đơn giản, dễ sử dụng

---

## ⚡ Ưu điểm bản Offline

* 🔒 **Bảo mật dữ liệu tuyệt đối** (không gửi ra ngoài)
* ⚡ **Ổn định** – không phụ thuộc Internet
* 💻 Phù hợp:

  * Cá nhân luyện tập tại nhà
  * Phòng tập không có mạng
  * Máy tính nội bộ

## 📌 Hướng dẫn sử dụng

1. Tải file `.exe`
2. Mở ứng dụng (có thể chạy trực tiếp)
3. Bật cảm biến nhịp đạp (BLE/ANT+)
4. Kết nối thiết bị trong phần cài đặt
5. Bắt đầu đạp xe và theo dõi dữ liệu

---

## ⚙️ Yêu cầu hệ thống

* Windows 11
* Bluetooth (BLE) hoặc USB ANT+ dongle
* Không yêu cầu Internet

---

## ⚠️ Lưu ý

* Đây là phiên bản **offline**, không có:

  * Bảng xếp hạng
  * Đồng bộ dữ liệu online
* Windows có thể cảnh báo khi chạy file `.exe` lần đầu:
  → Chọn **More info → Run anyway**

---

## 💾 Lưu trữ dữ liệu

* Dữ liệu được lưu **cục bộ trên máy**
* Không gửi lên server
* Người dùng toàn quyền quản lý dữ liệu
